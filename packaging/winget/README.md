# WinGet later

The v0.1.1 installer is intentionally versioned and checksum-stable for later WinGet submission.

- Installer: `https://github.com/jddev273/foldercompare/releases/download/v0.1.1/FolderCompare-v0.1.1-windows-x64-setup.exe`
- SHA-256: `374BB27AA166EFEF6360859F09FCABB074E2923B065668F6CC2958A457D6EC22`

Validate/generate the manifest against the then-current WinGet schema with `wingetcreate` before submission to `microsoft/winget-pkgs`.
